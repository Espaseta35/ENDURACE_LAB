ENDURACE LAB - WEB
==================

Archivos:
- index.html: página principal.
- inscripcion.html: formulario de contacto/solicitud.
- style.css: estilos responsive.
- logo.svg: logotipo SVG provisional.
- hero-triatlon.png: imagen principal generada para esta web.
- privacidad.html y aviso-legal.html: plantillas que deben completarse y revisarse antes de publicar.

ANTES DE PUBLICAR:
1. Sustituye [EMAIL] por tu correo real en index.html.
2. Despliega la mensajería propia (carpeta api/, Cloudflare Worker + base de datos D1):
   cd api && npm install && npx wrangler login
   npx wrangler d1 create endurace      -> copia el database_id en api/wrangler.jsonc
   npx wrangler d1 migrations apply endurace --remote
   npx wrangler secret put IP_SALT      -> escribe una cadena larga y aleatoria
   En Cloudflare activa Email Routing en endurace-lab.com y verifica el correo de NOTIFY_TO.
   npx wrangler deploy                  -> queda publicado en https://api.endurace-lab.com
   Ver solicitudes: npx wrangler d1 execute endurace --remote --command "SELECT * FROM leads ORDER BY created_at DESC"
   Prueba el formulario desde https://www.endurace-lab.com/inscripcion.html.
3. Completa tu titulación/acreditación deportiva real y define con precisión qué servicio puedes prestar legalmente. No publiques una titulación que no tengas.
4. Completa y revisa aviso-legal.html y privacidad.html con tus datos reales y los tratamientos de datos que efectivamente realices.
5. Revisa precios, plazos de respuesta, disponibilidad y condiciones antes de aceptar clientes.
6. Sustituye el logo provisional si ya tienes un logo oficial de ENDURACE LAB.

PAGOS CON STRIPE (preparado, DESACTIVADO hasta que lo actives)
=============================================================
La web ya tiene todo lo necesario para cobrar, pero no muestra ningún pago mientras
en pagos.js ponga  activo: false.

Antes de activarlo:
- Darte de alta como autónomo (Hacienda y Seguridad Social) y revisar con un gestor
  el IVA y cómo emitir facturas conforme a la normativa vigente.
- Comprobar qué titulación exige tu comunidad autónoma para ofrecer este servicio
  y ajustar cómo lo describes.
- Completar [NIF] y [DOMICILIO COMPLETO] en condiciones.html, privacidad.html y
  aviso-legal.html, y que un profesional revise las condiciones de contratación.

Para activarlo:
1. Crea tu cuenta en stripe.com con tus datos de autónomo y tu cuenta bancaria.
2. En Stripe > Catálogo de productos, crea:
   - Esencial, Pro y Premium, cada uno con 3 precios recurrentes:
     mensual (39 / 69 / 109 €), cada 3 meses (105 / 186 / 294 €), cada 6 meses (199 / 352 / 556 €).
   - Plan de carrera (129 €) y Videollamada (30 €) como pago único.
3. Crea un Payment Link para cada precio (11 en total). En cada uno, en
   "Después del pago", elige redirigir a: https://www.endurace-lab.com/gracias.html
4. Activa el portal de cliente (Ajustes > Facturación > Portal de clientes) y copia su enlace.
5. Pega los enlaces en pagos.js, cambia  activo: false  por  activo: true  y publica.

Cómo se usa: tras valorar una solicitud, envía al cliente su enlace personal, por ejemplo
  https://www.endurace-lab.com/pagar.html?plan=pro&periodo=mensual&email=correo@cliente.com
Ahí acepta las condiciones y el inicio inmediato del servicio y pasa al pago de Stripe.
Valores: plan = esencial | pro | premium | carrera | sesion;  periodo = mensual | trimestral | semestral.

Base de datos: si ya habías desplegado la API antes, aplica la nueva migración:
  cd api && npx wrangler d1 migrations apply endurace --remote

MEDIR LAS VISITAS (hazlo antes de empezar a promocionar la web)
==============================================================
1. Google Search Console (gratis): https://search.google.com/search-console
   - Añade la propiedad "Dominio" endurace-lab.com y verifícala con el registro TXT
     que te da Google, en la zona DNS de OVH.
   - En "Sitemaps", envía: https://www.endurace-lab.com/sitemap.xml
   - Revisa cada semana "Rendimiento": qué búsquedas te muestran y cuántos clics recibes.
2. Bing Webmaster Tools (gratis): importa la propiedad desde Search Console en un clic.
3. Analítica sin cookies, Cloudflare Web Analytics (gratis, no necesita mover el DNS):
   - En dash.cloudflare.com > Analytics & Logs > Web Analytics > Add a site,
     escribe www.endurace-lab.com y copia el "token" del fragmento que te da.
   - Pégalo en fx.js, en  const ANALYTICS_TOKEN = "";  y publica.
   - Añade a privacidad.html que mides visitas de forma agregada y sin cookies
     con Cloudflare Web Analytics.
